# Security Policy

## Scope

This repository contains the source for the Koglesh R. Murugan portfolio website.

## Reporting a vulnerability

Please do not publish sensitive security details in a public issue.

For a suspected security vulnerability, contact the project owner through the contact method listed on the live portfolio or GitHub profile and include:

- A short description of the issue
- The affected file, route, or behavior
- Clear reproduction steps when available
- The potential impact

Please avoid sharing passwords, API keys, tokens, or other private credentials in a report.

## Security principles

The project should:

- Keep secrets out of source control
- Validate untrusted input
- Avoid exposing server-side credentials to the browser
- Prefer secure external links
- Keep dependencies and CI tooling maintained
- Verify production changes before release
