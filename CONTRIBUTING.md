# Contributing to the Portfolio

This repository powers the Koglesh R. Murugan portfolio.

## Development

```bash
npm install
npm run dev
```

Before opening a pull request, run:

```bash
npm run lint
npx tsc --noEmit
npm run build
```

## Design principles

The portfolio should remain:

- Clear
- Fast
- Accessible
- Responsive
- Minimal
- Focused on real work

Avoid adding visual effects or UI elements that make the portfolio harder to navigate or understand.

## Content

Project descriptions should be accurate and should not claim features, results, or experience that cannot be supported by the actual project.

## Pull requests

Keep changes focused. Describe the purpose of the change and the checks you ran before submitting the pull request.
